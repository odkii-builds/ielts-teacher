# Release gate: платные функции

Платный ИИ-разбор, оплата и Premium НЕ выкатываются в продакшн (ielts.odkii-builds.ru), пока владелец проекта явно не сообщит, что выполнено всё из списка:

1. Robokassa активирована, «Робочеки СМЗ» работают, пароли магазина введены владельцем.
2. Уведомление Роскомнадзора принято (получен номер записи).
3. Оферта, политика и согласие на pay-сайте актуальны.
4. Платёжный сценарий проверен тестовым платежом.

До этого:
- ветка `feat/paid-preview` НЕ вливается в `main`;
- `app/js/paid.js` содержит флаг `enabled`: включается только на `*.vercel.app` и localhost и жёстко выключен на `odkii-builds.ru`;
- в превью ИИ и оплата имитируются, запросов к серверу нет.
